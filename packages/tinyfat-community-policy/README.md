# `@tinyfat/community-policy`

This is an independently written compatibility boundary for the fossified
Business OS build. It is not Rocket.Chat Enterprise license code.

The policy is deliberately simple:

- no commercial modules are active;
- no seat, contact, or action limits are enforced;
- no cloud license payload is applied;
- no air-gapped subscription restriction blocks messaging;
- paid feature callbacks do not run.

Community messaging and TinyFat customer-awareness features are governed by
the repository's own permissions and scoped relationship grants.
